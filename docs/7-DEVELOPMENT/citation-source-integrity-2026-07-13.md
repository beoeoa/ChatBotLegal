# Citation source integrity

Ask citations are built only from effective retrieval results. When an answer
names a law number or article, the citation builder matches that reference
against retrieved metadata before displaying the source.

Each citation preserves the original `source_url` stored with the legal
record and also exposes the internal viewer/PDF route for the same `doc_id`.
URLs are never generated by the language model; malformed non-HTTP source
values are discarded.
